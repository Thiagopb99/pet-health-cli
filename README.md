# 🐾 PetHealth CLI

**Versão:** 1.0.0  
**Autor:** Thiago de Pádua Bergamaschi

## 📖 Sobre o Projeto
O **PetHealth CLI** é uma solução simples e eficiente para resolver uma dor real de muitos tutores de animais: o esquecimento das datas de vacinação e vermifugação. O atraso nessas doses pode comprometer a saúde dos pets e da família.

## 🚀 Funcionalidades
- Cadastro de pets e vacinas.
- Validação de formato de data.
- Listagem de histórico de doses.

## 🛠️ Tecnologias
- Python 3.x
- Pytest (Testes Automatizados)
- Flake8 (Linting/Qualidade de código)
- GitHub Actions (CI/CD)

## 🔧 Como rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute a aplicação: `python -m app.main`
3. Para rodar os testes: `pytest`
4. Para rodar o lint: `flake8 .`
