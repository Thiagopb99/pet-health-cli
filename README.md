# 🐾 PetHealth CLI

Uma interface de linha de comando (CLI) para ajudar tutores a gerenciar o calendário de vacinas e vermífugos de seus pets, garantindo a saúde do animal e da família.

## 🚀 Funcionalidades
* **Cadastro:** Adição de pets, vacinas e datas das próximas doses.
* **Histórico:** Listagem completa dos registros de saúde.
* **[NOVO] Localização:** Busca de clínicas parceiras por CEP utilizando a API pública do ViaCEP.
